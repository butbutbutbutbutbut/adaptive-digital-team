# Adaptive Runtime Decision Layer

## Purpose

S2 extends the existing ADT Control Plane. It does not replace existing governance mechanisms.

## Position

```
Human Facing Layer
        |
Adaptive Runtime Decision Layer
        |
Existing Governance Control Plane
        |
Harness
```

## Responsibilities

- Risk-based governance selection
- Execution mode routing
- Checker trigger decisions
- Correction routing
- Human intervention point management

## Principle

Governance cost must remain lower than the cost of unmanaged errors.
