# S2-002-A Runtime Experiment

## Experiment

ADT Baseline Integration Experiment

---

## Objective

验证 ADT 在真实仓库协作中的运行能力。

测试范围：

- 上下文理解
- 仓库协作
- 反目标审查
- Human Facing
- Artifact Delivery

---

# Initial Finding

实验发现：

ADT 可以产生大量状态信息。

但状态透明不等于产物透明。

问题：

Human 知道系统做了什么，但不知道最终结果在哪里。

---

# Failure Pattern

错误模式：

```

Decision
↓
Status
↓
Completion

```

缺少：

```

Artifact
↓
Location

```

---

# Correction

增加：

Artifact Delivery Layer

完成链：

```

Decision
↓
Action
↓
Artifact
↓
Location
↓
Verification

```

---

# Human Point Finding

低风险任务不应该使用高强度治理。

错误：

```

确认
↓
确认
↓
确认

```

修正：

```

Batch Execution
↓
Checker
↓
Human Final Review

```

---

# Anti-goal

ADT 不应：

- 为了安全感增加无意义审批
- 用状态代替真实产物
- 消耗超过任务价值的人类注意力

---

# Result

本实验为 S2 后续版本提供：

- Delivery Layer
- Human Point Budget
- Artifact Existence Gate
